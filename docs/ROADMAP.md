# Product & Development Roadmap

## Phase 0 — Product Definition
- Brand direction
- Target persona
- MVP feature freeze
- Core user journey
- Core wireframes

## Phase 1 — Technical Specification
- Database / ERD
- REST API
- Auth / verification
- Group matching engine
- AI Mission engine
- Safety architecture
- Analytics event taxonomy

## Phase 2 — Prototype
- Clickable prototype
- 10–20 user interviews/tests
- Revise onboarding
- Revise activity discovery
- Revise post-activity relationship flow

## Phase 3 — MVP Development
- Mobile app
- Backend
- Admin moderation
- Push / chat
- Matching
- Mission
- Check-in
- Reports / blocks

## Phase 4 — Closed Beta
Initial target: 50–100 users in one local market.

Focus activities:
- English
- Photography
- Walking/running

Validate:
- Join conversion
- Attendance
- No-show
- Satisfaction
- Mutual connection
- Second Meeting Rate

## Phase 5 — Product-Market Fit Iteration
Only add features after core offline activity quality is validated.

Potential later features:
- User-created activities
- Venue partnership
- Deposit/payment
- Premium membership
- Host marketplace
- University/company programs
