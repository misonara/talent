# Talent — Purposeful Social App

> 사람을 찾지 마세요. 같이 할 일을 찾으세요.

## Project Vision

Talent는 소개팅 앱이나 단순 취미 모임 앱이 아니라, 사용자가 **GIVE(내가 나눌 수 있는 것)**, **GET(배우고 싶은 것)**, **INTEREST(함께하고 싶은 활동)**를 기반으로 3~5명의 소규모 오프라인 활동에 참여하고 그 과정에서 자연스럽게 관계가 형성되도록 하는 **목적형 관계 플랫폼(Purposeful Social App)** 입니다.

관계는 친구, 취미 동료, 네트워크, 프로젝트 파트너, 개인적인 인연 등으로 이어질 수 있지만, 연애 자체를 전면에 내세우지 않습니다.

## Core Principles

1. 사람보다 활동을 먼저 선택한다.
2. 외모 중심 스와이프를 사용하지 않는다.
3. 모든 모임에는 명확한 목적 또는 작은 결과물이 있다.
4. 초기 모임은 3~5명, 기본 4명으로 설계한다.
5. 모임 전 무제한 개인 DM을 제한한다.
6. 관계 선택은 실제 활동 이후에만 열린다.
7. 개인적 관심은 상호 선택일 때만 공개한다.
8. GIVE ↔ GET의 상호보완성을 핵심 매칭 신호로 사용한다.
9. AI는 사람을 평가하기보다 그룹 구성과 활동 진행을 돕는다.
10. 안전과 신뢰를 성장 기능보다 우선한다.

## Core Loop

가입 → 본인인증 → GIVE/GET/INTEREST → 활동 발견 → 참가 → 3~5명 그룹 형성 → 오프라인 활동 → AI Mission → 후기/관계 선택 → Mutual Connection → 다음 활동

## Initial Target

- 한국 27~39세 직장인
- 직장 밖에서 새로운 인간관계를 만들기 어려운 사람
- 소개팅 앱의 외모·스와이프 구조에 피로감을 느끼는 사람
- 동호회 가입은 부담스럽지만 새로운 경험과 사람을 원하는 사람
